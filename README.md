# CapoCalc

Free capo chord transposer: enter any chord and capo fret to get the exact shape to play, with sharp/flat toggle and transposed progressions.

**Live:** https://capocalc.fixoraa.tech

## Features

- Instant chord transposer: enter any chord and capo fret to get the shape to play
- Sharp/flat spelling toggle for the transposed chord names
- Common progressions library (pop, folk, worship, blues) transposed for your capo
